# План развития

Порядок ниже отражает зависимости и критерии готовности. Сроки и совместимость с конкретными версиями сторонних приложений не обещаются до проверки.

| Приоритет | Направление | Критерий готовности |
| --- | --- | --- |
| P0 | Надёжная переносимая установка | Чистая Windows-установка без WSL/Codex проходит настройку, self-test и файловую проверку в выделенном workspace; обновление сохраняет конфигурацию; откат возвращает предыдущий код |
| P0 | Матрица Windows/WSL | CI проверяет доступные платформы; ручной WSL smoke подтверждает Unicode, окружение и остановку только собственного дерева; результаты привязаны к версии |
| P0 | Конфиденциальность публикации | Сканирование исходников и готового пакета блокирует конфиги, ключи, реальные журналы и приватные артефакты; примеры остаются синтетическими |
| P1 | Совместимость локальных MCP | Для каждого заявленного адаптера зафиксированы транспорт, версия протокола и smoke-сценарий; проверены tools/list, один разрешённый вызов, результат и корректное отключение |
| P1 | Диагностика и восстановление | По коду ошибки понятно, что проверять; неизвестный исход не вызывает повтор действия; документирован разбор устаревших блокировок и повреждённого состояния |
| P1 | Codex Connect как адаптер | Документирован версионируемый контракт внешних скриптов; подтверждены exact-thread read и одна разрешённая UI-доставка с повторным чтением квитанции без повторной отправки |
| P1 | Управление локальными результатами | Описаны срок хранения, ручная очистка и резервирование; неизвестные операции и активные блокировки нельзя удалить незаметно |
| P2 | Дополнительные MCP-возможности | Новые транспорты, OAuth или запросы сервера клиенту добавляются только вместе с контрактом авторизации, тестами отказов и явным указанием поддерживаемых версий |
| P2 | Восстановление процессов после перезапуска | Проверенная идентификация владения исключает остановку постороннего PID; до реализации перезапуск не обещает восстановить process sessions |
| P2 | Подписанные релизы | Автоматическая сборка воспроизводима, проверка происхождения отделена от SHA-манифеста, процедура обновления и отката проверена |

## Правило расширения

Сначала добавляйте измеримый пользовательский сценарий, затем минимальный интерфейс и тесты. Не объявляйте поддержку Blender, Roblox, Adobe или любого другого продукта по одному наличию установленного приложения. Совместимость относится к конкретному MCP-серверу, версии и выполненному сценарию.

## Definition of done

Изменение готово, когда реализация, тесты, документация и инструкции агентам описывают одинаковое поведение; обязательные проверки проходят; конфиденциальные данные исключены; ограничения явно указаны. Успешная сборка не заменяет установку и проверку на целевом стенде.
