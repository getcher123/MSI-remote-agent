# Переход агентов на AIHub Remote Agent

Это инструкция по выбору инструментов в уже подключённом MCP-клиенте. Она не меняет настройки других сессий автоматически и не даёт им доступ к машине без подключения.

## Готовое поручение агенту

> Для разрешённой работы с подключённой машиной используй AIHub Remote Agent. Начни с `device_status` и убедись в устройстве, версии и доступных корнях. Для файлов используй `list_directory`, `file_info`, `read_file`, `read_multiple_files`, `write_file`, `edit_file`, `move_file`. Для терминала используй `start_process` и возвращённый session ID; PowerShell запускается как отдельный разрешённый executable с runtime=native (прежнее windows также поддерживается), WSL требует настройки. Для управления существующими Codex-сессиями используй пять `codex_*` инструментов, точный UUID и проверку квитанции. Для Blender, Roblox, Adobe и других приложений сначала проверь реально подключаемый MCP через `local_mcp_discover` → явную регистрацию → `local_mcp_tools`; названия и аргументы бери из схемы сервера. Каждое действие через `local_mcp_call` получает уникальный operation ID, который сохраняется для последующего `local_mcp_operation`. Не повторяй неизвестную мутацию или отправку Codex. При изменении файла проверяй актуальный SHA. Не обходи запрещённый путь через shell. Используй уже данное разрешение пользователя и продолжай задачу; новое разрешение требуется только для действительно нового действия вне её области. Не выводи секреты и не включай локальные настройки, журналы и квитанции в публичные артефакты. Полная инструкция: `skills/remote-machine/SKILL.md`.

## Проверка перехода

- Клиент видит ожидаемый 31 инструмент и действительно вызывает новый сервер.
- `device_status` показывает ожидаемое устройство; полная диагностика остаётся приватной.
- Чтение разрешённого тестового файла работает.
- Собственный диагностический процесс выдаёт результат и завершён подтверждённо.
- Для каждого приложения проверена его конкретная MCP-конфигурация; наличие приложения не равно доступному MCP.
- Для Codex отдельно проверяются doctor, exact-thread read и, только по разрешению, UI-доставка.

AIHub Remote Agent не обещает автоматического совпадения всех возможностей другого продукта. Доступны конкретные функции [каталога инструментов](TOOLS.md); UI-автоматизация чужих приложений и неподдерживаемые MCP-транспорты не появляются от смены названия плагина.
