# Модель угроз и ограничения

| Сценарий | Реализованный контроль | Практический предел |
| --- | --- | --- |
| Выход файлового инструмента за корень | Canonical/realpath-проверка и разрешения корня | Общая shell-команда имеет права OS-пользователя |
| Изменение неожиданной версии файла | SHA и точная замена | Для замены существующего файла вызывающая сторона должна передать актуальный SHA |
| Секрет в аудите | Allowlist метаданных | Вывод процесса и полные квитанции остаются приватными данными |
| Остановка постороннего процесса | Владение сессией; проверка идентичности в Windows launcher/WSL | Процессы, отделившиеся в другую session, и восстановление после перезапуска не гарантируются |
| Потеря старого вывода | Ограниченный буфер, абсолютные offsets и признаки потери | Это не бесконечный журнал |
| Подмена MCP-определения | Ссылка на источник и fingerprint | Внешний сервер сам остаётся доверенной зависимостью |
| Повтор мутации MCP после timeout | Квитанция до dispatch и исходный operation ID | Новый ID не является безопасным способом повтора |
| Повтор отправки Codex | Durable receipt, блокировка, проверка baseline/time/exact text | UI и внешние скрипты доступны не всегда |
| Неверный Codex-thread | UUID, title, cwd, idle и pending preflight | По одному совпадающему title выбирать нельзя |
| Сбой или повреждение состояния | Fail-closed чтение и отсутствие автоматического удаления lock | Для восстановления нужен ручной разбор |
| Изменённый пакет | SHA-манифест файлов | Без отдельной подписи он не доказывает происхождение |
| Вредоносная внешняя подсказка | Инструкции агента отделяют данные от пользовательского разрешения | Оператор обязан ограничивать доверие к подключаемым MCP |
| Компрометация MCP-клиента/туннеля | Доверенная учётная запись и внешняя аутентификация | Сам агент не является многоарендной системой изоляции |

Подробности хранения и правил раскрытия — в [SECURITY.md](SECURITY.md). Для неизвестного результата используйте маршруты восстановления из [RUNBOOK.md](RUNBOOK.md).
